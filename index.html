Sentimen

Klasifikasi berbasis kata kunci dan Machine Learning. Bisa analisa teks manual atau tarik komentar asli langsung dari Meta Graph API.

Proses Analisis Sentimen

🔤 Manual (Keyword-Based)

  • Text Cleaning: Hapus URL dan karakter khusus
  • Case Folding: Konversi ke lowercase
  • Tokenizing: Pecah teks menjadi kata-kata
  • Stopword Removal: Hapus kata umum (dan, yang, dll)
  • Keyword Matching: Cek kata positif/negatif
  • Scoring: Beri skor berdasarkan kecocokan
  • Classification: Tentukan label sentimen
Estimasi Akurasi
70-75%

🤖 AI (Machine Learning)

  • Text Preprocessing: Cleaning dan normalization
  • Tokenization: Pecah teks menjadi tokens
  • Embedding: Konversi ke vector representations
  • Context Analysis: Analisis makna dan konteks
  • Sentiment Classification: Model AI (Claude/OpenAI)
  • Confidence Scoring: Skor kepercayaan hasil
  • Reasoning: Penjelasan alasan klasifikasi
Estimasi Akurasi
85-95%
