Sentimen

Klasifikasi berbasis TF-IDF + Multinomial Naive Bayes (Machine Learning). Bisa analisa teks manual atau tarik komentar asli langsung dari Meta Graph API.

Proses Analisis Sentimen

🔤 Fallback (Keyword-Based)

  • Text Cleaning: Hapus URL dan karakter khusus
  • Case Folding: Konversi ke lowercase
  • Tokenizing: Pecah teks menjadi kata-kata
  • Stopword Removal: Hapus kata umum (dan, yang, dll)
  • Keyword Matching: Cek kata positif/negatif
  • Scoring: Beri skor berdasarkan kecocokan
  • Classification: Tentukan label sentimen
Estimasi Akurasi
70-75%

🤖 ML (TF-IDF + Naive Bayes)

  • Text Preprocessing: Case folding, hapus URL/mention/hashtag/emoji/angka/tanda baca
  • Stopword Removal: Hapus kata umum bahasa Indonesia
  • Stemming: Konversi ke kata dasar (Sastrawi)
  • TF-IDF Vectorization: Konversi ke vector representations
  • Multinomial Naive Bayes: Klasifikasi sentimen
  • Confidence Score: Probabilitas kelas (Positif/Netral/Negatif)
  • Classification: Label sentimen dengan confidence tertinggi
Estimasi Akurasi
85-90%
